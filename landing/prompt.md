# Prompt

Create a modern React landing page for SakuraPay — a payment processing
reliability simulator — with a full-screen HLS video background,
glassmorphic navigation header, and hero content positioned in the
bottom-left corner.

## Overview

Build a single landing page in React. The page should feature:

- A **full-screen HLS video background** that fills the viewport.
- A **glassmorphic navigation header**.
- **Hero content positioned in the bottom-left corner** of the page.
- SakuraPay branding: sakura-pink signal accent, "Every payment, settled
  exactly once." headline, live stream telemetry card bottom-right.
